Run it on the machine that hosts this installation

scripts/backup.sh copies the control plane and every portfolio database with VACUUM INTO, verifies each copy with PRAGMA integrity_check, and writes one compressed archive with a SHA-256 sidecar into $PROPTALLY_BACKUP_DIR (default ./backups). Add --tenant <id> for a single portfolio.

scripts/restore.sh verifies that sidecar and the integrity of every database before it writes anything, and copies an existing target aside rather than overwriting it.

Nothing in the app schedules a backup and no backup history is recorded, so a backup is only as recent as the last time that script ran. Run it from cron or a timer if you want it regular.
