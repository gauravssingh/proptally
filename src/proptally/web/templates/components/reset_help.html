{#- How an account holder gets a reset link. Shared by the standalone /auth/reset page and the sign-in box, so the two cannot drift. Two steps and one command: this is a page someone reaches while locked out, so it states what to do rather than why the security model is what it is. -#}

This host sends no email: your operator issues the reset link.

  1. Ask the installation operator to run python scripts/issue_password_reset.py --email <your-email>
  2. Paste the single-use token they give you below. It expires after two hours.
